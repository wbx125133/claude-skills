# AI 产品经理面试诊断与备战

> 对面试录音 / 文字转写做诊断复盘，并基于目标 JD 输出针对性备战方案，涵盖薪资谈判策略。

**Skill name**: `ai-pm-interview-diagnosis`

---

## 安装方法

把整个目录复制到 `~/.claude/skills/`，重启 Claude Code 后即可通过自然语言触发：

```bash
cp -R ai-pm-interview-diagnosis ~/.claude/skills/
```

## 触发说明

以下为 `SKILL.md` frontmatter 中的原始 description（决定 Claude 何时自动激活此 skill）：

> AI产品经理面试诊断与备战工具。当用户提到"面试诊断"、"面试复盘"、"面试录音分析"、"帮我看看面试"、"面试哪里有问题"、"面试表现分析"、"准备面试"、"面试辅导"、"模拟面试"时立即触发。也适用于用户说"我面试完了帮我分析一下"、"这个面试我感觉答得不好"、"帮我看看我的面试记录"、"面试官问了XX我不知道怎么答"等表达。即使用户只说"帮我分析一下这段对话"或"这个录音帮我看看"，只要涉及AI产品经理面试场景的诊断、复盘、备战、薪资谈判策略，都应触发此skill。覆盖从面试录音/文字转写的诊断分析到目标JD对齐的全场景面试准备。
