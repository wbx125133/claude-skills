# BRD Writer · 商业需求文档生成器

> 在投入时间之前判断一个方向值不值得做。引导式生成商业可行性分析文档。

**Skill name**: `brd`

---

## 安装方法

把整个目录复制到 `~/.claude/skills/`，重启 Claude Code 后即可通过自然语言触发：

```bash
cp -R brd ~/.claude/skills/
```

## 触发说明

以下为 `SKILL.md` frontmatter 中的原始 description（决定 Claude 何时自动激活此 skill）：

> 商业需求文档（BRD）引导式生成器——帮你在投入时间之前判断一个方向值不值得做。当用户提到"写BRD"、"商业需求文档"、"这个方向值不值得做"、"帮我判断要不要做"、"评估一下这个方向"、"可行性分析"时立即触发。也适用于"我有个想法想评估一下"、"帮我看看这个能不能做"、"这个方向靠谱吗"、"该不该做这个"等表达。即使用户只说"我想做XX，你觉得行吗"，只要意图是评估一个产品/业务方向的商业可行性，都应触发此skill。
