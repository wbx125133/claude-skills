# AI 产品经理简历撰写专家

> 覆盖 15-40k 全薪资段的 AI PM 简历撰写、诊断、JD 适配，把简历当作面向 HR 的产品来打磨。

**Skill name**: `ai-pm-resume-writer`

---

## 安装方法

把整个目录复制到 `~/.claude/skills/`，重启 Claude Code 后即可通过自然语言触发：

```bash
cp -R ai-pm-resume-writer ~/.claude/skills/
```
